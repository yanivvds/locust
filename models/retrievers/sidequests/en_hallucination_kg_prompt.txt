# CBS / RDF Data Cube primer
CBS tables follow the RDF Data Cube model: each table has dimensions (e.g. `Perioden` for time, `RegioS` for region, plus topical breakdowns like `SoortGoederen`) and measures (numeric quantities like population counts, energy use, monetary value). Dimension values are SKOS-coded (e.g. `GM0363`, `1900JJ00`, `A041907`); measures carry QUDT units (e.g. Gigajoule, Percent, Number, Euro). Tables are typically wide: many measure columns, a few dimension columns, no JOINs.

# Representative CBS dimension and measure label patterns
- Time: `Perioden` / `Periods` (year codes like `1998JJ00`, quarter codes like `2020KW01`)
- Region: `RegioS` / `Regions` (municipality codes `GM####`, province codes `PV##`, COROP `CR##`)
- Common topical dimensions: `Geslacht` (Sex), `Leeftijd` (Age), `Migratieachtergrond`, `Opleidingsniveau`, `BedrijfstakkenSBI2008`, `SoortGoederen`, `Energiedragers`
- Measure labels often end with a unit hint: `_kWh`, `_Mln_Euro`, `_Aantal`, `_Percentage`, `_Gigajoule`, `_x1000`
